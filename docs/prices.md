# Ціни лобі

Ціни більше не ведемо окремою таблицею: вони лежать у конфігах, щоб не було двох джерел.

- Розблокування зброї: `rooms/shared/weapons.json`, поле `price_soft` (кулаки й рогатка `default_owned`, без ціни).
- Прокачка пасток: `rooms/shared/traps.json`, поле `price_soft` на рядку кожного рівня (рівень 1 = 0: усі три пастки доступні одразу).
- Ціни за Robux: `lobby/shop_hard.json`.

Поточні числа взято з BAL-0003, де вони були цінами в забігу (віспи). Це **орієнтир співвідношень, а не фінальна економіка**: їх треба перерахувати під софт, який дає забіг (`run_rewards.json`, `wave_soft`). Наочна таблиця того, що вийде для ботів у кожній кімнаті:

```
python3 tools/validate.py --economy
```
