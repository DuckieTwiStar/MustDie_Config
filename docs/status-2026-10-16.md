## Дизайн 3.1 у конфігах (коміт 1f34216, BAL-0004, у main; в release ще не просувався)

Код гри ці поля ще не читає, нічого не зламано. Усе веде `tools/validate.py`.

| Що | Рішення |
|---|---|
| `tier` у зброї | прогрес (замки порталів, зброя ботів); fists 1, slingshot 1, bow 2, shotgun 3; не спадає з `order` |
| `order` | лише сортування; модифікація = `order` бази + 1..9 |
| Премодифікація | `base_id`, `tier` як у бази, без `price_soft` (нагорода або hard-магазин) |
| `price_soft` | у зброї є в усіх базових: fists 50, slingshot 150 (отримані одразу, ціна для бюджету ботів), bow 600 (~3 забіги Room 1), shotgun 2500 (~5 забігів Room 2); у пастках ціна кожного рівня в лобі |
| Пастки | усі три на рівні 1 доступні одразу (`default_owned`), у лобі купується лише прокачка |
| `unlock_weapon` у `room.json` | room1 = slingshot, room2 = bow, template = slingshot |
| `bots.json` | пул зброї (виключення `fists`, без премодифікацій), `trap_budget_mult` = 1: бюджет ботів на пастки = ціна зброї кімнати |
| Симулятор | `python3 tools/validate.py --economy` показує пул, бюджет і середні рівні пасток ботів по кімнатах |
| Тип `enemy` в каталозі | у пакеті Core (`ItemTypes`) змінено, **чекає публікації**; рядки ворогів в `items.json` додавати лише після неї |
| Інструкція для агента Степанова | `claude/item-catalog-instruction-for-room-agent.md` (= `docs/adding-items.md`) |

### Ціни (рішення Жені 16.10)

Лук ~3 забіги Room 1, дробовик ~5 забігів Room 2. Забіг = софт за хвилі + урон усіма ворогами + база з 50% HP: Room 1 ~192, Room 2 ~506. Звідси bow 600, shotgun 2500. Бюджет ботів: Room 1 = 150 (ціна рогатки), Room 2 = 600, Room 3 (дробовик) = 2500 = усі пастки на максимум (їх прокачка коштує разом 1050). Ціни прокачки пасток ще з BAL-0003 і не перераховувалися: на неї потрібно ~5.5 забігів Room 1, тобто пастки максимізуються раніше, ніж гравець купить лук. Це наступне, що варто підкрутити.

### Підтверджено Женею

- Премодифікація без бази рахується як tier бази.
- Повернення віспів за прибрану пастку: `rules.refund_share` = 0.5 (було 1), у `rules.json` BAL-0005.
- Ціна є в усіх базових зброй; `default_owned` лише позначає її отриманою в профілі.
