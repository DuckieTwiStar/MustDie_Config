# Чекліст карти кімнати (обов'язково для всіх румів)

29.10.2026, Агент J за рішенням Жені. Доповнює контракт карти (`mustdie-rooms-instructions.md`, розділ 4). Зразок: Room 4 (`Room4_Greybox`), подробиці в `docs/room4-notes.md`, кроки 9–10.

## 1. Бар'єр кімнати спаунера: на кожному вході, у всіх румах

Кожна кімната/зона, звідки виходять вороги, закрита для гравців **завжди**, а не лише у фазі дверей (`SpawnDoor` відкривається з початком хвиль). Загін з воротами (`SpawnGate`) теж: бар'єр одразу за стулкою з боку загону, щоб після виламування гравець не заходив усередину.

Модель `SpawnBarriers/SpawnBarrier_<sN>` (атрибут `SpawnerId`), лише карта, без коду:

| Частина | Що | Налаштування |
|---|---|---|
| `Collider` | невидима стіна в прорізі | `Transparency 1`, `CanCollide` і `CanQuery` = true завжди: не пускає гравців і ботів, зупиняє постріли (`CombatService` бере Exclude-рейкаст) і привид пастки. Ворогів не зачіпає (вони йдуть маршрутом без фізики). |
| `Line` | червона неонова лінія на підлозі біля порогу | `Neon`, колір (255,40,40), 0.5 stud завширшки |
| `Glow` | світіння від лінії вгору | невидима деталь + `SurfaceGui` (LightInfluence 0) з `Frame` і `UIGradient` (знизу 0.35 → згори 1), ~7 studs |
| `Shimmer` | ледь видима силова стіна | `ForceField`, той самий червоний, `Transparency 0.82` |
| `Sparks` | іскри вгору від лінії | `ParticleEmitter` Rate 10, Lifetime 1.2–2.2, тег `MapFx` (слабкий режим) |

Усе візуальне: `CanCollide/CanQuery/CanTouch/CastShadow = false`, атрибут `MinimapIgnore = true`. Перевірка в Play: відкрити двері (або дочекатися хвилі), зайти в кімнату не можна, стрибок не допомагає, вороги виходять.

Скрипт-будівник для Room 4 є в історії сесії (функція `build(id, x0, x1)`); для нової кімнати достатньо координат прорізу.

## 2. Декор: злиття для слабких пристроїв

Наприкінці роботи над декором злити деталі (`GeometryService:UnionAsync`), вигляд не змінюється:
- повторювані моделі (шафки, двері): один юніон-шаблон на варіант + клони на всі місця;
- решта: непрозорі деталі без колізії/запитів/тіней/тегів/атрибутів/дочірніх об'єктів, по папці + **матеріалу** + квадрату 64×64 studs.
- **Не зливати**: `Neon` (гасне світіння), прозорі, деталі з `SurfaceGui`/`Decal`, колайдери, деталі з `MaterialVariant`. Один юніон = один матеріал (змішаний тьмяніє, особливо `Metal`).

## 3. Мінікарта

1. Декору поставити `MinimapIgnore = true` (інакше папки декору з назвою `Walls` малюються як стіни, а юніони як великі прямокутники).
2. Сходи без `TrapFloor`: `MinimapKind = "floor"`; ворота загону (`Panel`): `MinimapKind = "door"`.
3. Запекти з Command Bar: `require(game.ServerStorage.TowerDefenseServer.MinimapBaker).bake()`, потім File → Publish. Перепікати після кожної зміни карти.

## 4. Точка появи гравця

`SpawnLocation` повернути передом (`LookVector`, синя грань Front) **назустріч ворогам**: персонаж і камера після появи дивляться туди, куди дивиться спавн. У Room 4 спавн дивився на печать, і гравець з'являвся спиною до маршруту (боти розвертаються самі, тому з ними проблеми не було). Швидко: `SpawnLocation.CFrame = CFrame.lookAt(pos, точка_звідки_йдуть_вороги)` (на рівні pos.Y).
