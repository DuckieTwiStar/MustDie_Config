# Фази ворога, щит, бос (етап 1, 02.11.2026)

Поля `enemies.json`: `phases`, `boss`, `hp_by_players` (опис у README).

## Фази
`phases` — список по порядку. Перша застосовується при спавні. Перехід: `until.shield_broken` (щит фази знято) або `until.hp_below` (частка HP тіла, 0..1). Остання фаза без `until`. Поле, не задане у фазі, лишається з рядка ворога. Швидкість фази множиться на індивідуальний jitter ворога.

## Щит
`shield_hp` — окремий пул перед тілом. Поки він >0, весь урон іде в щит, броня тіла ігнорується, множник — `shield_mult[damage_type]` (типово 1). Урон по щиту йде у внесок (contribution) і в RunScore. Знятий щит з `until.shield_broken` = наступна фаза. Клієнт: блакитний контур поки щит є, червоний після зміни фази, спалах на переході.

## Бос
`boss: true` -> смуга зверху (HP + щит). Дійшов до печаті = миттєва поразка (`setBaseHp(0)`). `hp_by_players[n]` — HP за кількістю гравців на старті забігу (n обмежується 1..4).

## Тестові значення (feat/phases)
`shieldbearer` (щит 140: фіз ×0.5, вогонь/шок ×1.5; потім rage швидше й боляче), `warlord` (3000..10500 HP, fury з 40% HP). Room 3: хвилі 4-5. Це чернетка балансу, не для release до перебудови v0019.
